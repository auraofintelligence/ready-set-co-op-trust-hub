## Hand over unfinished work

Paste this file into **Prompt 1** in the [lesson prompt exports](LESSON-PROMPT-EXPORTS.md). Luke will guide the first implementation, help capture the workflow and test the lesson for consistency and accuracy. Use the recording for actual control names and screens.

- **Lesson ID** `plfc-handover-open-actions`
- **Course** PLFC officer onboarding and handover
- **Audience** An incoming or outgoing Point Lookout Fishing Club officer
- **Outcome** Prepare three open actions with an owner, due date and source reference. Flag one issue for the first-week check-in.
- **Source** The changeover and first-week lessons in the PLFC course draft. Confirm details of the procedure with Luke. [Course draft source](../../migrations/0010_learning_courses.sql)
- **Intended audience for the finished lesson** The authorised PLFC training group.
- **Capture environment** Demo or sanitised view. If a suitable view is unavailable, demonstrate the task with a clearly labelled fictional handover sheet.

## How to test this lesson

Show one worked entry before the learner writes the other two. Ask what is missing from “follow up equipment”, and why a source reference matters. Check the practical for an owner, deadline and source on every action and one issue for the first-week check-in.

Luke can put the same brief into two models and follow both drafts against the recorded workflow. Compare whether each capture plan was usable, the labels and steps were accurate, the questions had defensible answers and how much correction each output took. Keep both drafts, the human corrections and the approved result as a reference example.
